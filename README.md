# The Price of Democracy

Five-slide Renaissance-themed HTML presentation about compulsory voting, including John Stuart Mill, Timothy Feddersen, Oprea et al., and Anthony Fowler.

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch** and select **main** / **/(root)**, then select **Save**.

Expected public URL once Pages is enabled: https://catherineresoco-netizen.github.io/ENGLC1000/

## Controls

Left/right arrow keys: navigate; **N**: speaker notes; **S**: sources; **Esc**: close notes or sources.
